## What's winning in 2024–2026 (condensed)

- **Caves of Qud 1.0** (Dec 2024, universal acclaim, Hugo + IGF Narrative): the modern-interface bar for traditional roguelikes; **optional run modes** (Classic permadeath / Roleplay with checkpoints / Wander) broadened the audience without diluting identity; a real beginner tutorial; narrative depth as the differentiator.
- **Path of Achra**: the "condensed roguelike" — near-zero input friction (auto-move, one-key resolution), build expression through **passive powers that trigger on events** and chain into each other; short runs, huge replay.
- **Shattered Pixel Dungeon**: quarterly cadence of QoL + one system rework at a time; six heroes as the replay engine; next up: a **self-contained vault microcosm where your items don't come with you**.
- **Hades II** (1.0 2025, ~5M): narrative persistence — the world *remembers between runs and says so out loud*; incremental unlock drip.
- **Slay the Spire 2** (EA, 97% positive): refinement over reinvention; the one misstep — patching out overpowered fun — triggered a review-bomb until reverted. Player power fantasies are sacred; buff alternatives, don't gut.
- **Mewgenics** (1M week-one): cross-run **legacy systems** (breeding lines) as the core hook — the strongest commercial validation yet of "your history is the content."
- **Roguelike Celebration 2025** themes: art direction inside procgen worlds; narrative through randomness; accessibility.

The meta-trend: traditional-roguelike DNA is mainstream-viable when input friction dies, the world visibly remembers, and permadeath is an option rather than a wall.

## (a) New improvement candidates (ranked by impact ÷ effort)

1. **Auto-explore + smarter travel (S–M).** Proof: Path of Achra's whole thesis; DCSS's `o` is the genre's most-loved key; Qud's travel QoL. Fit: floors are 160×50 and about to hold ~17 monsters — walking them by hand is the tax; the session layer already has BFS travel (`travel.ts`) and this session literally built a BFS auto-explorer for testing. Add: explore-until-interesting (`o`), travel-to-stairs/minimap-click, auto-pickup toggles (gold always; configurable for consumables). Deterministic-safe (intents, not engine changes).
2. **Run modes at character creation — Classic / Wanderer (M).** Proof: Qud 1.0's audience unlock. Fit: `encodeActiveRun` makes floor-entry checkpoints nearly free; Wanderer = resume-at-floor-top on death with no Hall record (or a marked one) — leaderboard integrity preserved by gating records to Classic, which the repository layer already structures. This is the single biggest reach-expander available.
3. **Guided first descent (S–M).** Proof: Qud shipped a beginner tutorial for 1.0 and reviewers singled it out. Fit: quickstart + seeded runs + the onboarding-hint system exist; a fixed-seed scripted "first thread" floor with staged hints (move, bump-open, loot, eat, fight, descend) closes the new-player cliff cheaply.
4. **Triggered passive affixes — one engine hook, three payoffs (L, staged).** Proof: Achra's trigger-chemistry is why a minimal game has massive build depth; SPD's reworks trend the same way. Fit: the artifacts spec explicitly deferred an equipped-effects/trigger hook; #121 curses and artifact tier-2 both want it; a small closed trigger vocabulary (`on-kill`, `on-hurt-below-half`, `on-floor-enter`) reusing existing `EFFECT_IDS` gives enchantments, curses, and future artifacts a shared chassis. Build once, feed three roadmap items.
5. **The Deep's Codex — make the remembering visible (M).** Proof: Hades II's narrative persistence; Qud's Hugo-winning lore surfacing; Mewgenics' legacy hook. Fit: Hall records, discovered items, slain monster kinds, and (soon) artifact provenance all exist as data — a codex screen with lore snippets per entry turns existing state into felt memory. Pairs with the achievements system for unlock hooks.
6. **Post-run share card (S).** Proof: seed-sharing/leaderboard culture around StS2 and dailies. Fit: a run-summary card (hero, depth, cause, score, artifact stints) rendered client-side for copy/save; multiplies #115's daily-seed loop when it lands.
7. **Set-piece floors per depth band (M).** Proof: SPD's planned no-items vault microcosm; RC2025's art-direction-in-procgen talks. Fit: the vault system + themes already support authored spaces; one signature floor event per band (a flooded gallery, an ember choir, a silent web) breaks the 20-floor sameness the consistency review flagged from another angle. Could later merge with #119 branching.

## (b) Sharper shapes for queued items

- **#116 bones/haunts → make the dead speak.** 2026's lesson (Hades II, Qud) is that persistence lands when it's *narrated*, not just spawned. Echoes should carry a line derived from their record ("Kaelen. Depth 14. The spiders.") in encounter and kill text — the record data already holds everything needed.
- **#121 curses → fun-first curses (StS2's review-bomb lesson).** Curses that create play ("heals hurt, but corpses explode") beat gotcha stat drains; telegraph through lore/appearance so identification (#145) is a skill, not a coin flip.
- **#123 unlocks → Hades-style drip.** One meaningful unlock roughly per run early on; the light-out traits directive fits as the first darkness track — sequence unlocks as tracks (darkness, economy, callings) rather than a flat pool.

## (c) Anti-recommendations — trends to deliberately skip

- **Co-op/multiplayer** (StS2's headline feature): collides with the deterministic single-seed engine, server authority model, and solo-descent fiction. Cost is enormous, identity fit is zero.
- **Action/real-time drift** (Hades II, Megabonk): the deliberate turn-based read-the-board loop *is* the game; animation (#160) adds juice without touching timing — that's the right lane.
- **Meta-progression power creep** (generic roguelite +5%-damage trees): directly violates the ruled principle that victory = skill + gathered loot. Keep unlocks lateral (variety, options, knowledge) — never vertical power.
- **Checkpoint-as-default**: offer Wanderer mode, but Classic stays the default and the only Hall-recorded mode; Qud shows opt-in is enough.
- **Nerf-first balancing**: when the spawn/loot tuning lands and something proves degenerate-fun, prefer buffing alternatives or pricing it — the StS2 episode shows how expensive deleting fun is.
